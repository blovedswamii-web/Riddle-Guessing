# Riddle Guessing Game

A fun interactive riddle guessing game where players can test their wit and problem-solving skills!

## Description

Riddle Guessing is a game application that presents users with various riddles and challenges them to guess the correct answers. Perfect for brain training, entertainment, and friendly competitions.

## Features

- Multiple riddle categories
- Difficulty levels (Easy, Medium, Hard)
- Score tracking
- Hints system
- Timer-based challenges

## How to Play

1. Start the game
2. Select a riddle category or difficulty
3. Read the riddle carefully
4. Enter your answer
5. Get instant feedback on your guess
6. Track your score and progress!
